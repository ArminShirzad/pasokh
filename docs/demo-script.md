# Demo video script

A 4-minute screen recording, in Persian, of a fresh install going live. Every
step runs in the test lab, so it can be recorded without a real account and
without showing anyone's data. Record at 1280×800, Persian interface.

| Time | On screen | Say (Persian) |
|---|---|---|
| 0:00 | The installer finishing in a terminal; the browser opening the setup page | «پاسخ را با یک دستور نصب می‌کنیم؛ رایگان و متن‌باز، روی سرور خودتان.» |
| 0:20 | Creating the admin account; the dashboard in Persian | «فارسی، راست‌چین، با تقویم شمسی.» |
| 0:35 | Templates → "Branches menu" → Use; the links to the paused smart replies | «با الگوها شروع می‌کنیم. همه چیز متوقف ساخته می‌شود تا اول خودتان ببینید.» |
| 0:55 | Opening the menu smart reply, editing the greeting, switching it on; the phone preview | «پیش‌نمایش دقیقاً همان چیزی است که مخاطب می‌بیند.» |
| 1:20 | Test lab: DM «شعبه», tap «کرج», the branch answer | «در آزمایشگاه بدون اینستاگرام امتحان می‌کنیم.» |
| 1:45 | Templates → "Price list as a carousel"; Showcase editor with photos | «لیست قیمت به‌صورت کارت؛ یک بار ویرایش، همه‌جا به‌روز.» |
| 2:10 | Campaigns → new campaign on any post, handing off to the price smart reply | «کامنت ← دایرکت. اینستاگرام به غیرفالوور دکمه نمی‌دهد، پس اول متن می‌رود و بعد از جوابش، کارت‌ها.» |
| 2:35 | Test lab: comment «قیمت», the text reply, answer «اوکی», the carousel | |
| 3:00 | Forms: the sign-up template; test lab answers «۰۹۱۲ ۳۴۵ ۶۷۸۹»; Results; download for Excel | «شماره با رقم فارسی هم درست ذخیره می‌شود و فایل اکسل فارسی را درست نشان می‌دهد.» |
| 3:30 | Reports; Contacts with the phone | «همهٔ کارکرد در یک گزارش.» |
| 3:45 | The GitHub page | «کد روی گیت‌هاب است؛ AGPL. با Zernio یا اپ متای خودتان کار می‌کند.» |

Do not record: API keys, real Instagram accounts, real phone numbers (use
09123456789-style test numbers), or the `.env` file.
