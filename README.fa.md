# پاسخ · Pasokh

**اتوماسیون متن‌باز دایرکت و کامنت اینستاگرام، روی سرور خودتان.**
فارسی و انگلیسی، راست‌به‌چپ، نصب با یک دستور.

[English](README.md) · [نقشهٔ راه](docs/ROADMAP.md)

</div>

کسی زیر ریلز شما «لینک» کامنت می‌گذارد؛ پاسخ برایش دایرکتی با لینک می‌فرستد،
در صورت تمایل اول از او می‌خواهد پیج را فالو کند، و زیر کامنتش هم جواب عمومی
می‌دهد. همین کلمه‌ها در دایرکت و جواب استوری هم کار می‌کنند. همان کاری که
سرویس‌هایی مثل دایرکتم ماهانه برایش پول می‌گیرند، این بار نرم‌افزار آزاد و روی
سرور خودتان.

پاسخ از دو راه به اینستاگرام وصل می‌شود: **زرنیو** (ساده‌ترین راه؛ بدون بررسی
اپلیکیشن توسط متا و رایگان برای دو حساب اول) یا **اپلیکیشن متای خودتان**. فقط
از API رسمی استفاده می‌شود: نه اسکرپینگ، نه رباتِ مرورگر، و هرگز رمز اینستاگرام
شما را نمی‌خواهد.

## امکانات فعلی

- **کامنت ← دایرکت**: کلمهٔ کلیدی برای یک پست، همهٔ پست‌ها یا ریلز بعدی؛ تطابق کامل یا بخشی از کلمه.
- **پاسخ عمومی** زیر کامنت، به‌صورت تصادفی از چند متن مختلف.
- **فالو اجباری**: لینک فقط بعد از فالو ارسال می‌شود.
- **فعال‌سازی از دایرکت و جواب استوری** با همان کلمه‌ها.
- **لینک‌های قابل‌ردیابی** با آمار کلیک برای هر کمپین، تا سه لینک در هر دایرکت.
- **صندوق پیام**: خواندن و جواب دادن دایرکت‌ها از داخل داشبورد.
- **گزارش دایرکت‌ها** با دلیل هر ارسال، ردشدن یا خطا.
- **تیم**: چند حساب اینستاگرام، اعضا و نقش‌ها.
- **رابط فارسی** با تقویم شمسی، یا انگلیسی؛ هر کاربر خودش انتخاب می‌کند.

به‌زودی (جزئیات در [نقشهٔ راه](docs/ROADMAP.md)): پاسخ با عکس، ویدیو، ویس و
کارت محصول (ویترین)، منوی دکمه‌ای زنجیره‌ای، پاسخ مخصوص هر استوری، پیام
خوش‌آمدگویی، پیام‌های پیگیری زمان‌دار، فرم‌ساز، پاسخ با هوش مصنوعی، کامنت لایو
و پیامک.

## نصب

یک سرور **خارج از ایران** لازم دارید (اینستاگرام و زرنیو از داخل ایران در
دسترس نیستند)، با حداقل ۱ گیگابایت رم (۲ گیگ راحت‌تر است؛ پاسخ در حالت عادی
حدود ۵۰۰ مگابایت مصرف می‌کند) و داکر. اگر داکر روی لینوکس نصب نباشد، نصب‌کننده
خودش نصبش می‌کند.

**سرور لینوکس یا مک**

</div>

```bash
curl -fsSL https://raw.githubusercontent.com/ArminShirzad/pasokh/main/install.sh | bash
```

<div dir="rtl">

**ویندوز (Docker Desktop)، برای امتحان**

</div>

```powershell
irm https://raw.githubusercontent.com/ArminShirzad/pasokh/main/install.ps1 | iex
```

<div dir="rtl">

نصب‌کننده زبان و روش دسترسی به سرور را می‌پرسد:

| گزینه | کاربرد |
|---|---|
| تونل سریع کلودفلر | برای شروع و امتحان. دامنه نمی‌خواهد. آدرس با ری‌استارت تونل عوض می‌شود و پاسخ خودش وب‌هوک زرنیو را به‌روز می‌کند. |
| دامنهٔ خودتان | برای استفادهٔ واقعی. رکورد A دامنه را به IP سرور بدهید و پورت ۸۰ و ۴۴۳ را باز کنید؛ گواهی HTTPS خودکار گرفته می‌شود. |
| تونل دائمی کلودفلر | استفادهٔ واقعی بدون باز کردن پورت. در کلودفلر تونل بسازید، یک آدرس را به `http://web:3000` وصل کنید و توکن را وارد کنید. |
| فقط همین کامپیوتر | فقط برای دیدن رابط کاربری؛ اینستاگرام به آن نمی‌رسد. |

در پایان، آدرس را نشان می‌دهد. بازش کنید، حساب مدیر را بسازید و بعد:

۱. **تنظیمات ← زرنیو**: کلید API زرنیو را وارد کنید (بدون محدودیت، خواندن و نوشتن، با دسترسی Inbox)، پروفایل را انتخاب کنید و حساب اینستاگرام را اضافه کنید.
۲. **کمپین‌ها ← کمپین جدید**: کلمهٔ کلیدی، متن دایرکت، لینک و فالو اجباری (اختیاری).
۳. با یک حساب اینستاگرام دیگر همان کلمه را کامنت کنید و نتیجه را ببینید.

## نگهداری

</div>

```bash
cd ~/pasokh
docker compose ps                                   # وضعیت سرویس‌ها
docker compose logs -f web worker                   # دیدن لاگ‌ها
docker compose pull && docker compose up -d         # به‌روزرسانی
docker compose exec web npm run user:password -- you@example.com   # بازنشانی رمز
docker compose exec -T postgres pg_dump -U pasokh pasokh > pasokh-backup.sql   # پشتیبان دیتابیس
```

<div dir="rtl">

از فایل `‎~/pasokh/.env` حتماً نسخهٔ پشتیبان بگیرید؛ کلید رمزگشایی اتصال‌های
ذخیره‌شده در آن است.

## قوانین اینستاگرام همچنان برقرارند

- برای هر کامنت فقط یک پاسخ خصوصی، تا ۷ روز بعد از آن.
- از اوایل شهریور ۱۴۰۵ اینستاگرام در پاسخ به کامنتِ کسی که شما را فالو نکرده،
  دکمه و کارت را قبول نمی‌کند. پاسخ برای این افراد پیام متنی می‌فرستد و بعد از
  جوابشان با دکمه ادامه می‌دهد.
- پیام بیش از ۲۴ ساعت بعد از آخرین پیامِ مخاطب پذیرفته نمی‌شود.
- وضعیت فالو فقط برای کسانی معلوم است که به شما پیام داده‌اند.
